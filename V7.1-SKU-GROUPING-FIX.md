# V7.1 — SKU grouping fix

V7 correctly detected camera angles, but required AI family wording or pHash similarity to be too close. Different views of the same 3D product can produce very different perceptual hashes, and AI can phrase the same construction differently.

V7.1 groups with hybrid evidence:
- exact ETag duplicate detection
- category bucket
- normalized construction tokens
- color as supporting evidence
- pHash as supporting evidence
- closure / silhouette / shape conflict guards

Example phrases such as `low-top hook-and-loop athletic sneaker with thick sole`, `hook-and-loop strap casual sneaker`, `low-top athletic sneaker with thick sole`, and `low-top casual sneaker with hook-and-loop strap` now resolve to one SKU family while still preserving front/back/side/three-quarter as separate views.
