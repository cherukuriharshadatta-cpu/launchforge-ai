# LaunchForge V7.4 — Studio Redesign + 360 Reliability

## What changed
- Launch headline now types itself on load with a professional caret animation.
- Catalog redesigned as a dark inventory command center with stronger metrics, search/filter and bulk actions.
- Launch Intelligence redesigned with a sticky section navigator, premium SKU reconstruction panel, Media Doctor, Creative Lab, immersive media and capability map.
- Website, Video and Publish surfaces share the same polished studio language.
- 360 viewer no longer depends on `/api/spin` or Cloudinary Product Gallery client-side list configuration. It immediately rotates the Cloudinary-delivered product-angle frames already in the catalog.
- Cloudinary server configuration is validated through `/api/cloudinary/status`; the UI shows a clear configuration banner instead of failing later with `cloud_name is missing`.
- `lib/cloudinary.ts` no longer overwrites `CLOUDINARY_URL` configuration with undefined credential fields.

## Important for local setup
Copy `.env.local` into the **V7.4 `launchforge-ai` folder** before starting the dev server, then restart it.
